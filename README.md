# الورشة المتنقلة بالرياض - صيانة وإصلاح السيارات عند باب المنزل 🚗🔧

تطبيق وواجهة احترافية لخدمات الورشة المتنقلة وصيانة السيارات الميدانية في جميع أحياء ومناطق مدينة الرياض على مدار 24 ساعة.

---

## 🌟 الميزات الرئيسية

- **تغطية شاملة لأحياء الرياض**: تغطية حصرية لكافة أحياء ومحاور مدينة الرياض (شمال، شرق، غرب، جنوب، ووسط الرياض).
- **حجز مباشر وسريع عبر الواتساب**: إمكانية إرسال طلب الصيانة ونوع السيارة والموقع مباشرة للفني عبر الواتساب بضغطة زر.
- **خدمات صيانة ميدانية متكاملة**:
  - 🔋 **تغيير واشتراك البطاريات**: توريد وتركيب بطاريات أصلية مع ضمان معتمد واشتراك طوارئ بالموقع.
  - ⚡ **إصلاح كهرباء السيارات**: فحص وإصلاح المولد (الدينامو)، السلف، الفيوزات، والضفائر الميدانية.
  - 🛠️ **الميكانيك السريع والفرامل**: تغيير فحمات وهوبات الفرامل، السيور، وطلمبات البنزين والماء.
  - 💻 **فحص الكمبيوتر والبرمجة**: كشف أخطاء OBD2، برمجة الحساسات والقير، ومسح لمبات الطبلون.
- **تواصل وسريع**: أزرار اتصال مباشر وحجز سريع عبر الواتساب مع رقم موحد لخدمة العملاء.
- **تصميم تجاوبي وأنيق**: متوافق تماماً مع الهواتف الذكية والأجهزة اللوحية والمكتبي (Responsive Dark UI).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Backend / Server**: Express (Node.js) with Vite Middleware
- **Build Tools**: esbuild, tsx

---

## 🚀 كيفية التشغيل والرفع (Getting Started)

### 1. تثبيت الحزم (Install Dependencies)

```bash
npm install
```

### 2. تشغيل السيرفر في وضع التطوير (Development Mode)

```bash
npm run dev
```

سيتم تشغيل التطبيق على الرابط المحلي: `http://localhost:3000`

### 3. بناء المشروع للإنتاج (Production Build)

```bash
npm run build
```

### 4. تشغيل سيرفر الإنتاج (Production Start)

```bash
npm start
```
